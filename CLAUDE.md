# CLAUDE.md

Project rules for working on DistroDAW.

## Git and GitHub

- No commit, PR, or change description pushed to GitHub may carry any attribution to Claude. This includes `Co-Authored-By` trailers, "Generated with" lines, and any mention of Claude or Anthropic in commit messages, PR titles, or PR descriptions.
- All commits are written in English.
- Every new feature gets its own branch. Each branch contains one commit per implemented characteristic of that feature, rather than a single squashed commit.
